# Cut Tab

The **Cut** tab is where you inspect clips after scene detection and rerun cutting on the selected source when the first pass is too coarse or too sensitive.

## Scene Detection Presets

Use the top-left controls when a source is selected:

| Preset | Sensitivity | Minimum cut length | Best for |
|---|---:|---:|---|
| **Cut Standard** | 3.0 | 0.5 seconds | Dialogue, lectures, tutorials, and general footage |
| **Cut Fast** | 5.0 | 0.33 seconds | Trailers, music videos, montage sequences, and fast-cut social clips |

Higher sensitivity creates more cuts. Lower minimum cut length allows shorter clips. If a trailer still looks under-cut, use **Cut Fast** first; if it creates too many fragments, switch back to **Cut Standard**.

The Cut tab only changes clip boundaries inside the project. It does not modify the source video file on disk.
